# Fuentes para la imagen social

`next/og` admite TTF, OTF y WOFF, pero no los WOFF2 de la web. Estas fuentes
estáticas oficiales se usan únicamente al generar el PNG de la comunidad.
No se descargan durante el build y no se añaden al JavaScript del navegador.
